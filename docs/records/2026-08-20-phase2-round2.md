## 1. 设计规范（ui-ux-pro-max 产出 + 项目约束）

- **风格**：Modern Dark Cinema 变体（暗色电影玻璃）——深紫黑渐变底 + 金色强调 + 紫罗兰辅助
- **配色**：bg #0f0a1e→#0a0812、金 #e8c97a、紫 #5E6AD2、文字 #EDEDEF/#8A8F98、hairline rgba(255,255,255,0.08)、卡片玻璃 rgba(255,255,255,0.04-0.06)+blur(14-16px)、圆角 14-16px
- **字体**：微软雅黑（**不引入外部字体**——Electron 离线打包兼容）；标题 700+字距+金色渐变文字（background-clip）
- **动效**：纯 CSS（项目未装 motion 库）：入场 fade+up 200-300ms、stagger、hover 上移+金色描边+微光投影、tab 切换 fade+slide、toggle 滑块 200ms
- **图标**：内联 SVG stroke 24x24（禁止 emoji 做图标；技能卡片保留技能目录自带 emoji 图标）
- **ui-ux-pro-max 检查清单遵守**：无 emoji 图标、cursor-pointer、hover 150-300ms、focus 可见、对比度

## 2. 关键交互变更（SelectScreen）

```
旧：新建故事必须打字输入名称+路径
新：左列直接展示项目卡片（已有项目点击即选中）→ 右列显示该项目对话记录
    「＋ 新建项目」→ 表单：名称输入 + 路径选择：
        Electron：window.__KOTONOHA_PICK_DIR__（preload → ipcMain dialog.showOpenDialog 目录选择）
        浏览器：手动输入提示 + 快捷路径（E:\Kotonoha / D:\ / E:\）
    「＋ 新对话」→ 默认名「对话 N」（N=存档数+1）→ onNewSave
```
