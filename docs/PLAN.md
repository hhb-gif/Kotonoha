# Kotonoha 最小闭环规划

> 记录时间：2026-08-19
> 状态：✅ 已完成（2026-08-19），详见 `docs/records/2026-08-19-minimal-loop.md`

## 目标

跑通最小闭环：视觉小说风前端壳 + dsh 真实 agent 后端。

- 对话：模型与用户交替（真实 LLM 驱动）
- 功能包装：项目 = save(存档)，加载 = load(读档)
- 单模型单角色，架构预留多模型多角色（不同模型 = 不同角色）

## 范围（本次只做）

| 模块 | 说明 |
|---|---|
| 前端壳 | 全屏背景 + 底部对话框 + 角色立绘 + 打字机 + 选择肢 |
| 后端 | dsh（provider=opencode / deepseek-v4-flash-free） |
| 通信 | dsh 对外协议（HTTP/WebSocket/JSON-RPC，待验证） |
| 存档/读档 | 会话持久化，视觉小说式命名 |
| 素材 | agnes 生成立绘 + 背景图 |

## 不做（后续）

- 多角色/多模型、情绪识别、语音、PixiJS 特效、存档进度系统

## 阶段与分工（≤3 子 agent 并行）

| Agent | 任务 | 产出 |
|---|---|---|
| A | 验证 dsh 对外协议：启动 web、探测端点、消费事件流、发消息、工具执行 | 验证报告 + 对接示例 |
| B | 搭 React+Vite 视觉小说前端壳（mock 数据流，接口留好） | 可运行前端 |
| C | agnes 生成立绘 ×1 + 背景图 ×2 | 素材文件 |

## 决策点（岔路停下问用户）

1. dsh 协议不可用 → 换方案：直接调模型 API / dsh CLI 管道
2. agnes 生图失败 → 占位图，不阻塞
