# v0.2.4 规划：CLI 形态 + MCP 配置化 UI（拾遗第一批）

> 剩余拾遗四项，本批做两个价值最高的：CLI（harness 终端形态，对标 opencode/hermes）+ MCP 配置化（补全外接体验闭环）。
> 存档时间线 + i18n 留第二批。

## 任务 A：CLI 形态（agent 侧）

### A1. 入口（src/cli.ts，编译为 dist/cli.js）
- `node dist/cli.js chat "消息"`：单条模式——创建/复用 CLI 会话 → 发送 → 流式输出到 stdout → 退出
- `node dist/cli.js repl`：交互模式——readline 循环，输入即对话，流式打印；命令：/exit /new /model <provider> <model> /tools /help
- `node dist/cli.js --help`
- package.json scripts：`"cli": "node dist/cli.js"`

### A2. 组装复用
- 复用 bootstrap.ts 的 bootstrap(hub)（引擎/db/providers/tools/auth 全套）
- CLI 自己的 hub：事件直接映射到 stdout（text-delta → process.stdout.write；emotion-change 忽略或暗色输出；finish 后换行）
- 审批：CLI 模式规则 = 只读工具 allow、写工具 bash 等保持 ask → 终端问询（readline Y/n）→ approver.respond；或简化：CLI 默认 auto-allow 全部（--yolo 标志）+ 默认 ask 终端确认。**实现终端确认**（体验更好）
- 会话隔离：label「CLI」，cwd = process.cwd()；每次 chat/repl 默认新建（--session <id> 复用）

### A3. 输出规范
- text-delta 直接写（不换行）；turn 结束换行
- 工具调用：打印 `[tool] name(args摘要)` 行
- 颜色：ANSI（可选，简单加）

## 任务 B：MCP 配置化（后端 + 前端）

### B1. 后端（settings 持久化 + RPC）
- 配置存储：settings 表 key `mcp:servers` = JSON 数组 [{id, type:'stdio'|'sse', command?, args?, url?, headers?, enabled}]
- RPC（ops 注入）：
  - `mcp.servers.list` → {servers: [...配置 + 运行状态 status/tools]}
  - `mcp.servers.add`（payload {server}）→ 保存 + 立即连接
  - `mcp.servers.remove`（{id}）→ 断开 + 删除
  - `mcp.servers.toggle`（{id, enabled}）→ 连接/断开
- bootstrap：启动时按配置表自动连接 enabled 的 server（mcp 模块的 connectServer 已有）
- 现有 mcp.status 保持（读运行态）

### B2. 前端（ESC MCP 页签增强）
- 现有 McpPanel：只读状态列表 → 增强：
  - 「添加服务器」表单（type 下拉 stdio/sse；stdio: command+args；sse: url；备注 id）
  - 每个服务器行：状态徽章 + 连接/断开按钮 + 删除按钮
  - 保存后刷新列表
- bridge：addMcpServer/removeMcpServer/toggleMcpServer 三方法
