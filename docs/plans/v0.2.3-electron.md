# v0.2.3 Electron 完善规划（M5）

> 目标：桌面体验生产化——托盘常驻、全局唤起、安全加固、用户级扩展目录。

## 任务

### 5.1 系统托盘（electron/main.cjs）
- Tray（icon: build/icon.ico）+ 右键菜单：
  - 显示主窗口（show + focus）
  - 分隔线
  - 退出（真正 quit，跳过最小化拦截）
- **关闭行为**：点窗口 × → 隐藏到托盘（不退出）；托盘菜单「退出」才真退出
  - app.isPackaged 才启用托盘常驻（dev 模式关窗即退出，避免开发困扰）
  - 设置面板加开关「关闭时最小化到托盘」（默认开）——经 IPC 读取（kotonoha:settings 由渲染层持有，主进程通过 IPC 拉取或存 electron-store 式简单 JSON；简化：主进程存 userData/tray-pref.json）
- 托盘单击 → 显示窗口
- before-quit 现有 agent 清理逻辑保持

### 5.2 全局快捷键
- globalShortcut.register('Control+Shift+K', toggle 主窗口 show/focus 或 hide）
- 注册失败（冲突）→ console.warn 静默降级
- will-quit 时 unregisterAll

### 5.3 安全加固
- **CSP**：生产模式（file://）注入 meta CSP：`default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: file:; connect-src 'self' ws://127.0.0.1:* http://127.0.0.1:*; font-src 'self' data:`
  - dev（vite 5173 + HMR ws）不加（会挡 HMR）
  - index.html 加 meta（生产构建包含；dev 用 vite 变换——直接在 index.html 加 meta 会同时生效 dev……dev 下 connect-src 需含 5173 ws。方案：main.cjs 生产模式 session.webRequest.onHeadersReceived 注入 CSP header（不动 index.html，dev 天然不受影响）
- **sandbox 评估**：preload.cjs 当前用 contextBridge+ipcRenderer（sandbox:true 兼容）——尝试 webPreferences sandbox: true；若 preload 里有不兼容用法（require 其它模块）则记录并保持 false，文档说明
- 校验 existing：contextIsolation:true ✓ nodeIntegration:false ✓

### 5.4 用户级插件目录（agent 侧）
- bootstrap.ts：loadPlugins 现在扫 `tools/plugins`（项目内）——增加第二个目录 `~/.kotonoha/plugins/`（用户级，后加载=可覆盖同名？简单化：两个目录工具都注册，重名时 warn + 先到先得）
- external tools 同理：扫 `~/.kotonoha/tools/*.tools.yaml`
- 目录不存在静默跳过（已有逻辑）
- 文档：README 或 plugins/example 注释说明用户级目录路径
