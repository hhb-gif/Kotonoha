# v0.2.5 规划：存档时间线 + i18n（拾遗第二批，最后两项）

## 任务 A：存档时间线（对话历史回放可视化）

### A1. 数据
- bridge 加 `getSessionHistory(sessionId)` → session.history RPC（后端已有）
- 历史 events：user/message + assistant/message（消息级，工具调用不单独存）

### A2. 时间线视图（前端）
- 入口：SessionPanel 加「时间线」按钮 → 打开全屏弹层（复用 settings-overlay 模式）或独立面板
- 渲染：竖向时间轴（复用 BondPanel 时间线样式模式 ep-bond-timeline）
  - 每条消息一个节点：左侧圆点+竖线，右侧卡片
  - 用户消息：标记「你」+ 文本摘要
  - 言叶消息：标记「言叶」+ 文本
  - 显示序号（第 N 轮）+ 文本前 120 字（点击展开全文）
- 顶部：会话名 + 消息总数 + 关闭按钮
- 空态：还没有对话记录
- 文案用 i18n t()（key 放自己的包文件，见 B 设计的多包合并）

## 任务 B：i18n 国际化

### B1. 框架（src/i18n/）
- `src/i18n/index.js`：`t(key)` 函数 + `setLanguage(lang)` + `getLanguage()`
  - 多包合并：zh（默认兜底，value=key 本身可省略）+ en + ja + extras（并行子 agent 追加用）——init 时 Object.assign 合并
  - 语言存 settings（kotonoha:settings.language，默认 'zh'）
  - t(key)：当前语言包查 key，缺 key 回落 zh，zh 没有显示 key 本身
- 语言包：`src/i18n/zh.js`（key=中文文案，value=中文）、`en.js`、`ja.js`（翻译）
- key 规范：直接用中文文案作 key（迁移成本低、zh 兜底天然成立）

### B2. 组件迁移（静态 UI 文案）
范围（按组件逐个过）：MainMenu / DialogBox / TopBar / InputBar / PlayerInput / SettingsPanel / EscapePanel 壳 + panels/*（除 D1 并行新增的 TimelinePanel——它的 key 由 D1 自己放 extras）/ SelectScreen / Onboarding / ApprovalModal / LogViewer
- 不迁移：错误消息/日志/toast 动态拼接（第二轮再说）、bridge 层消息
- React 更新：语言切换后组件重渲染——用简单方案：语言存 localStorage，setLanguage 后 window.location.reload()（最可靠，视觉小说应用可接受）

### B3. 语言切换 UI
- SettingsPanel 顶部加「语言 / Language」下拉：中文 / English / 日本語 → setLanguage + reload

## 分派（2 个并行子 agent）

| 子 agent | 范围 | 冲突约定 |
|----------|------|----------|
| D1-timeline | bridge.getSessionHistory + TimelinePanel（新文件）+ SessionPanel 加入口按钮 + i18n extras 包 | 不动其它组件；key 放 `src/i18n/extras.js` |
| D2-i18n | i18n 框架 + zh/en/ja 包 + 全组件迁移（除 TimelinePanel） + 设置面板语言切换 | 不动 SessionPanel（D1 在改）和 TimelinePanel |

## 验收

### A（时间线）
1. build 通过；进对话 → ESC 会话页签 → 时间线 → 历史消息按序渲染（轮次/角色/摘要/展开）
2. 空会话空态正确

### B（i18n）
1. build 通过；默认中文界面与现在完全一致
2. 切 English → 主菜单/设置/ESC 页签文案变英文；切回中文恢复
3. ja 包就位（可抽查几个 key）
4. t() 缺 key 回落中文（不显示裸 key）

## 约束

- D1/D2 并行：D2 最后统一 build 时如遇 D1 的 extras 未就绪，忽略（extras 是独立文件）
