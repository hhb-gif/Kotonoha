## 四、M6a 任务分解（子 agent）

| 子 agent | 任务 | 依赖 |

## 五、验收标准（M6a）

1. 言叶立绘随对话情绪切换（思考/开心/道歉状态可演示）
2. 场景切换有过渡动画；打字机有音效（可关）
3. 现有功能零回归（verify-all + 前端 build + 对话全链路）
4. 打包 v0.2.0 发布

## 六、风险

| 风险 | 对策 |
|------|------|
| 立绘表情图资源缺失 | 用现有 character.png 生成差分（色相/亮度变化兜底），或 AI 生成 |
| 情绪标签不准 | system prompt 严格约定枚举 + 解析容错（无标签默认 neutral） |
| 音效资源体积 | 短音效（<50KB），按需加载 |
| TTS 音色生硬 | 系统TTS 先行，后续可换神经TTS |
